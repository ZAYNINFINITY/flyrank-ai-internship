# Plinth Roadmap

## Milestones

Each milestone maps to a visitor experience layer, not a feature checklist.

- [x] Milestone 1 — Museum Foundation (Week 3: routes, layout, nav, Tailwind tokens)
- [x] Milestone 2 — Museum Entrance (Week 5: home "Enter the Museum" CTA, entrance hall, visitor context)
- [x] Milestone 3 — Reception (Week 5: reception hall, door-based navigation between spaces, visitor flow)
- [x] Milestone 4 — AI Communication Layer (Week 5: streaming chat UI, provider abstraction, prompt system, tool calls, error recovery)
- [ ] Milestone 5 — Curator Intelligence (context-aware guide, MCP integration, museum knowledge)
- [ ] Milestone 6 — Galleries (project exhibit rooms, image rendering, room-by-room navigation)
- [ ] Milestone 7 — Collections (developer profiles, project grouping, discovery paths)
- [ ] Milestone 8 — Discovery (search, recommendations, visitor journey tracking)
- [ ] Milestone 9 — Public Beta (real content, real users, performance tuning)

# Break Your Own Site — Week 7

## What I tested

### Form / input edge cases
- **Empty form submission**: Login form (`/login`) validates email + password client-side; empty submit shows validation errors, no crash
- **Garbage input**: Random strings in email field → "Please enter a valid email address" validation message
- **Rapid double-submit**: Login form prevents duplicate submission via disabled state during validation
- **XSS in search**: Explore page has no search input; chat panel (`/assistant`) sanitizes AI responses

### Browser / device testing
- **Firefox desktop**: 3D museum renders correctly, scroll rail works, gyro fallback to mouse parallax
- **Safari desktop**: 3D renders, no WebGL issues, touch emulation works
- **Chrome mobile (devtools)**: Touch drag scrolls the rail, gyro permission prompt appears on iOS simulation
- **Reduced motion**: `prefers-reduced-motion: reduce` → 2D `SurfaceRenderer` loads instead of 3D, no animation
- **No WebGL2**: Capability gate correctly falls back to 2D renderer
- **Low memory (<2GB)**: Capability gate falls back to 2D renderer

### Link / navigation testing
- All nav links (Museum, Explore, About) work correctly
- `/exhibit/[username]` → 2D portfolio pages render for all 4 developers
- `/exhibit/e/[id]` → 3D exhibit rooms load with correct data
- `/collection` → collection page renders
- `/gallery` → gallery with optional collection filter works
- `/dashboard` → placeholder "Sign in to manage your exhibit"
- `/health` → developer health check renders all exhibits
- `/playground` → dev playground
- 404 page → "No exhibit here yet" with link to `/explore`

### 3D-specific breakage
- **Scroll past rail limits**: Clamped to RAIL_START (26) and RAIL_END (-18), no fly-through
- **Click non-interactive area**: No inspect dialog opens, no error
- **E key with no nearby item**: No action, prompt shows nearest item
- **Escape during inspect**: Closes dialog correctly
- **Door auto-open**: Triggers at correct Z thresholds, no visual glitch
- **Text walls toggle**: Switches between 3D and flat renderer without crash
